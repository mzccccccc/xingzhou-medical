# 后端已办事项记录

> 更新日期：2026-10-06

## 已办

### 1. NIfTI → DICOM 转换

- 完成 NIfTI 格式影像到 DICOM 格式的转换，使原始 NIfTI 数据可被 PACS / OHIF 阅片器直接加载。

### 2. 私有数据上传 Orthanc 服务器

- 将私有病例数据（转换后的 DICOM）上传至 Orthanc 服务器，作为 DICOMweb 数据源供前端查询与浏览。

### 3. `pnpm dev:orthanc` 命令切换服务器

- 通过 `pnpm dev:orthanc` 启动 OHIF 开发服务并切换到 Orthanc 服务器数据源。
- 该命令位于 `ohif/package.json`，转发至 `@ohif/app` 的同名脚本，关键配置：
  - 代理目标：`http://localhost:3000/pacs/dicom-web`（Nginx 反代）
  - 代理域名：`http://localhost:8042`（Orthanc）
  - 路径重写：`/pacs/dicom-web` → `/dicom-web`
  - 应用配置：`config/docker-nginx-orthanc.js`
- 配套命令：
  - `pnpm dev:orthanc:no:cache`：禁用缓存启动
  - `pnpm orthanc:up`：通过 Docker Compose 启动 Nginx + Orthanc（`platform/app/.recipes/Nginx-Orthanc/docker-compose.yml`）
